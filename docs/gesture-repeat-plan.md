# 手势翻页双模式改动规划

在电脑端摄像头开关旁增加「单次翻页 / 停留连翻」，默认选中「单次翻页」。牌环和大图共用这一选择。两种模式均为左挥看下一张、右挥看上一张。

## 交互约定

| 操作 | 单次翻页 | 停留连翻 |
| --- | --- | --- |
| 居中停稳后挥手 | 立即翻一张 | 立即翻一张 |
| 挥手后停在同侧 | 等待回中 | 在触发方向的侧边区连续停留 450 毫秒后翻第二张，随后每 650 毫秒翻一张 |
| 短挥后直接收手 | 回中停稳即可再挥 | 只翻第一张；离开侧边区即取消连翻，回中停稳即可再挥 |

侧边区按已有的镜像掌心坐标计算：左侧 `x ≤ 0.25`，右侧 `x ≥ 0.75`。450 和 650 毫秒是首轮真机试用值。停留时间从**有效挥手之后首次进入对应侧边区**算起，单纯把手伸入画面边缘不会翻牌。

真机反馈后的调整：左右采用同一套向外位移计算。进入侧边后增加相同的 3% 画宽缓冲，左侧超过 `x = 0.28`、右侧低于 `x = 0.72` 才判为收手退出；缓冲内轻微回摆不取消或重启计时。缺手与后台中断仍立即取消。位移阈值统一使用小量数值容差，避免镜像浮点误差造成边界行为不一致。

## 按文件实施

1. **在[手势判定](../src/lib/handSwipe.ts)中处理连翻。** 增加 `SwipeMode = "single" | "repeat"`。沿用当前的居中、挥手方向判定和回中参考点 `returnCenterX`。首次挥手成功时照常返回方向；仅在连翻模式额外记录该方向。尚未到达侧边时允许手继续向外移动；若先回到起点附近，则取消本次连翻资格。到达侧边后，用现有 `update(..., time, ...)` 的帧时间判断停留。每次到期只返回一次方向，再从当前帧计算下一次到期时间。离开侧边后进入原有回中流程，收手经过另一侧也不会反向触发。
2. **在[摄像头识别](../src/hooks/useHandSwipe.ts)中同步模式。** 将调用改为 `useHandSwipe(onSwipe, swipeMode)`。模式切换时清空待连翻方向、计时和采样，重新提示居中，复用当前摄像头会话。连翻依赖新的视频帧推进；任何缺手帧立即取消待连翻，超过现有跟踪宽限的帧间隔也取消。页面隐藏时通过 `visibilitychange` 清除状态，关闭、报错或卸载时走现有释放流程。恢复后从居中开始，避免补翻后台积累的页数。
3. **在[画廊](../src/components/CardGallery.tsx)中增加选择和指引。** 用一组带「手势翻页方式」标签的单选按钮保存 `swipeMode`，与现有牌环 / 大图的 `mode` 独立。每次识别事件继续走现有 `onSwipe → step`，使按钮、手势和页码使用同一套选牌逻辑。扩展 `SwipeGuide` 和 `gestureHints`，按阶段提示：就绪时显示「左挥下一张，右挥上一张」；进入侧边时显示「保持在左侧即可连续看下一张」；连翻时显示「正在连续看下一张，手移回中间即可停止」。右侧对应「上一张」。只在阶段变化时更新提示。

## 验收重点

- **识别测试**：[用模拟轨迹和时间戳](../__tests__/handSwipe.test.ts)覆盖左右两侧。单次模式长停只产生一次事件；连翻模式在侧边停留 449 毫秒仍只翻一张，首个达到 450 毫秒的有效帧再翻一张，之后按 650 毫秒间隔触发。
- **中断测试**：[摄像头测试](../__tests__/useHandSwipe.test.tsx)覆盖收手、丢手、后台恢复和运行中切换模式。中断后没有多余翻页，切换翻页方式无需重新授权摄像头。
- **真机试用**：在牌环与大图各做一次「短挥即收手」和「左侧停留连翻两张后回中」，再用右手势反向操作。重点看能否停在想看的那一张，再决定是否调整停留时间和连翻间隔。
